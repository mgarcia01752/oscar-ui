OSCAR-UI brand assets

light: dark lettering for light surfaces.
dark: light lettering for dark surfaces.
Primary SVG/PNG files include a theme background.
Files ending -transparent have an alpha background for UI and README placement.
Files ending -icon contain the square symbol on a transparent background.
Horizontal PNG: 2400 x 720. Icon PNG: 1024 x 1024.
SVGs are real vector paths, including outlined lettering; no external fonts or raster images.

Palette: navy #0B3153, blue #176BC1, cyan #4BE0D5; dark surface #0B1728.
Maintain clear space of at least one status-light column around the mark.
Use horizontal marks at 300 px wide or larger; use the icon for smaller placements.

References examined (read-only):

https://github.com/PyPNMApps/PyPNM
